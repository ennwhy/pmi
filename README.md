# PMI Pakistan — Trade Connect (NuStream demo)

Retailer e-ordering over WhatsApp, with distributor notification and loop closure.
Built from Philip Morris Pakistan's returned pre-demonstration brief (NS-PDB-v1).

- **Portal** — live order queue, e-ordering adoption, on-shelf availability,
  planogram and share of shelf, in-store availability, coverage, order analytics.
  Live: https://ennwhy.github.io/pmi/
- **Chat** — the retailer and distributor WhatsApp conversations, recorded from
  the flow engine. Live: https://ennwhy.github.io/pmi/chat/

Both pages are self-contained: no build step, no dependencies, no network calls.
All figures are synthetic and for demonstration only. Trade rates are indicative
and were not supplied by PMI.

The interactive build — a working WhatsApp bot against the Meta Cloud API, with a
live portal — is a separate Node project and is not published here.
